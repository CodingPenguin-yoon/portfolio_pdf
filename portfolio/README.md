# Document Portfolio

발표자료가 아닌 읽는 포트폴리오를 제작하는 작업 공간이다.

## 결과물

- 210 × 297mm 단위로 끊어지는 A4 페이지형 웹 문서
- 동일한 콘텐츠를 사용하는 9페이지 A4 세로 PDF

## 콘텐츠 원칙

- 프로젝트는 `문제 → 해결 → 결과` 순서로 설명한다.
- 기술과 아키텍처는 선택 이유를 설명할 때만 사용한다.
- 개인 기여, 검증 근거와 한계를 명확하게 구분한다.
- GitHub, PR, 테스트와 시연 영상은 주장에 연결되는 증거로 제공한다.
- 결과 수치는 측정 조건과 포함 범위를 함께 적는다.
- 현재 구현 범위와 아직 구현하지 않은 범위를 분리한다.

## 프로젝트 순서

1. Heimdall
2. Gjallar
3. K-Le-PaaS

## 실행과 PDF 내보내기

```bash
cd site
npm run dev
```

```bash
cd site
npm run pdf
```
